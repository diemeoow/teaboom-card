## Запуск локально

Проект не требует сборки — достаточно открыть `index.html` в браузере:

```bash
git clone https://github.com/diemeoow/teaboom-card.git
cd teaboom-card
```

Затем откройте `index.html` в браузере, либо запустите локальный сервер, например:

```bash
npx serve .
```
